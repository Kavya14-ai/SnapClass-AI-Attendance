# SNAP CLASS – AI-Powered Attendance Management System

SNAP CLASS is an AI-powered attendance management system designed to simplify and automate student attendance using face and voice recognition. It provides teachers with an easy-to-use platform for managing students and maintaining attendance records efficiently.

 **Live Demo:** https://snapclass-ai-attendance-u4brb67de8nky7maki5jrz.streamlit.app/

 **Tech Stack:** Python, Streamlit, Supabase, AI/ML

 **Key Features:**
- Face and voice-based attendance
- Teacher registration and login
- Automated attendance management
- Supabase database integration
- Interactive and user-friendly dashboard
